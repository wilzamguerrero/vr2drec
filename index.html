        Ayuda

        1. Abre un archivo con Fuente → Abrir archivos o arrástralo sobre el reproductor. El vídeo no se sube a ningún sitio.
        2. También puedes pegar una URL directa (el servidor remoto debe permitir CORS).
        3. Con Modo 360/VR activo, arrastra sobre la imagen para rotar la cámara y usa la rueda para el zoom.
        4. Recortar salida te deja dibujar el marco final sobre la imagen: define proporción, resolución y encuadre de una vez.
        5. Grabar vista guarda exactamente lo que ves, ya reproyectado a plano.

        Atajos

        • Espacio reproducir / pausar
        • ← → saltar 5 s (con Shift: 1 s)
        • WASD rotar · QE horizonte
        • + − zoom · 0 recentrar
        • K keyframe · R grabar · C recortar
        • F pantalla completa · M silenciar · Esc cerrar ventana
